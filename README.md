# Smart-Door-Locking-System

The Smart Door Locking System Using STM32 is an embedded systems-based security solution designed to provide secure, automated, and remotely accessible door locking functionality. The project integrates an STM32 microcontroller, an electronic solenoid door lock, a matrix keypad, Bluetooth communication, and a web-based monitoring interface to create an intelligent access control system. The primary objective is to replace conventional mechanical locking mechanisms with an electronically controlled security system that provides password-based authentication and real-time locking status monitoring.

The core of the system is an STM32 microcontroller, which acts as the central processing and control unit. It is responsible for handling keypad inputs, executing password verification algorithms, controlling the solenoid lock, and managing communication with the external monitoring interface. The firmware is developed in Embedded C, allowing direct interaction with the microcontroller’s GPIO peripherals and communication interfaces. The STM32 GPIO pins are configured to interface with the matrix keypad and other external hardware components. The keypad scanning mechanism is implemented through row-and-column detection, enabling the microcontroller to identify individual key presses and construct the password entered by the user.

The password authentication mechanism is implemented at the firmware level. When a user enters a password through the matrix keypad, the STM32 captures each key input, temporarily stores the entered sequence in a buffer, and compares it against the predefined authentication password. The firmware incorporates input validation and conditional control logic to determine whether access should be granted or denied. If the entered password is correct, the microcontroller generates an output signal to activate the electronic locking mechanism. Incorrect password entries are rejected, and the system maintains the locked state to prevent unauthorized access. This approach demonstrates the implementation of embedded decision-making, input processing, memory management, and hardware control.

The physical locking mechanism is implemented using a 12V DC solenoid door lock, which operates through electromagnetic actuation. Since the STM32 operates at a lower logic voltage and cannot directly drive the solenoid due to its high current requirements, an appropriate driver circuit or switching arrangement is used between the microcontroller and the lock. Upon successful authentication, the STM32 generates a control signal that activates the switching circuit, energizing the solenoid and changing the locking mechanism’s state. Once the authorized unlocking period is completed, the firmware deactivates the output to restore the locked condition. This demonstrates the practical integration of low-voltage digital control electronics with higher-power electromechanical devices.

Another important feature is the integration of Bluetooth-based wireless communication to enable remote monitoring of the door’s locking status. The STM32 communicates with a Bluetooth module through a serial communication interface, such as UART, using transmit and receive data channels. The firmware handles the exchange of status information between the controller and the wireless communication module. Whenever the door transitions between locked and unlocked states, the corresponding status is transmitted wirelessly. This information is subsequently made available through a web-based monitoring interface, allowing users to remotely observe the current locking status without physically interacting with the door.

The web interface provides a convenient monitoring mechanism by displaying the door’s operational status based on the information received through the Bluetooth communication link. This introduces the concept of hardware-to-software communication, where embedded firmware interfaces with wireless communication hardware to make physical device information accessible through a digital platform.

From an embedded engineering perspective, the project involved several important concepts, including STM32 GPIO configuration, matrix keypad interfacing, UART serial communication, digital input processing, output control, password authentication algorithms, peripheral interfacing, and real-time hardware status management. Particular attention was given to coordinating the different hardware peripherals through structured firmware logic to ensure reliable operation and prevent unintended locking or unlocking conditions.

Overall, the Smart Door Locking System demonstrates the practical application of microcontroller-based embedded system design, peripheral integration, wireless communication, and electromechanical control. It provides hands-on experience in developing firmware that connects digital authentication mechanisms with physical hardware while extending device functionality through wireless status monitoring. The project serves as a foundation for more advanced embedded security applications involving IoT connectivity, access control, remote device management, and intelligent building automation
